An injury set consists of a casualty set each injury, with at least 1 AIS (Abbreviated Injury Scale) severity score.
AIS values are: 
- 1.0: Minor
- 2.0: Moderate
- 3.0: Serious
- 4.0: Severe
- 5.0: Critical
- 6.0: Fatal
