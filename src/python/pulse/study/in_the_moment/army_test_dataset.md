### In The Moment - Training Dataset

The following tables provide data associated with the various army injuries.
Each table is generated using the Pulse StandardMale patient as the casualty.
Each patient has a single injury provided.
An injury set consists of 5 instances of each injury, each with an increasing injury severity.
Severities used are [0.9, 1.9, 2.9, 3.9, 5.0].
